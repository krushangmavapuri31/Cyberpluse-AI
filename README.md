# CyberPulse AI

CyberPulse AI is a cybersecurity news automation system that collects the latest cyber threat news, filters important security events, summarizes them using AI, and delivers reports via email twice daily.

## Features
- RSS-based news collection
- Cybersecurity keyword filtering
- AI summarization (coming soon)
- Severity classification (coming soon)
- Email reports (coming soon)

## Tech Stack
- Python
- Feedparser
- FastAPI
- OpenAI API
- PostgreSQL
